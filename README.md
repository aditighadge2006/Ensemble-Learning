# Ensemble Learning

## Practical No. 5 – Artificial Intelligence and Machine Learning

### Aim
To implement and compare different ensemble learning techniques using machine learning classification algorithms.

### Dataset
Breast Cancer Wisconsin Dataset (Scikit-learn)

### Algorithms Implemented

**Base Classifiers:**
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes

**Ensemble Classifiers:**
- Stacking Classifier
- AdaBoost Classifier
- Voting Classifier (Hard Voting)

### Performance Evaluation
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Log Loss
- Confusion Matrix
